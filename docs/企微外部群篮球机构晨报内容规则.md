# 企微外部群篮球机构晨报内容规则

> 状态：已确认  
> 生效日期：2026-08-25  
> 适用渠道：企微外部客户群每日篮球机构晨报

## 一、晨报为谁解决什么问题

晨报面向篮球培训机构的创始人、校长、教务负责人和教练负责人，由三个板块组成：国内篮球短讯、国外篮球短讯、机构提醒。新闻负责提供新信息；机构提醒负责提示当前经营节点，例如开学排课、续费衔接、教练交接、请假补课和家长沟通。

机构提醒按以下顺序确定：

```text
当前日期 → 机构经营节点 → 受影响角色 → 容易出问题的流程 → 一条具体提醒
```

不能从一个赛果、一名球员的表现或一场热门比赛直接推导招生、续费或培训需求。机构提醒不从当天新闻硬推结论。

## 二、每日固定结构

每天只发一条合并晨报。群内使用精简版，不展示链接、发布时间和编辑审校字段；这些内容保留在后台证据记录中。群内结构如下：

```text
【赛小蜂篮球机构晨报｜8月25日】

🇨🇳 国内篮球短讯
1️⃣ 标题＋一句事实
2️⃣ 标题＋一句事实（可选）

🌍 国外篮球短讯
1️⃣ 标题＋一句事实
2️⃣ 标题＋一句事实（可选）

📣 机构提醒
围绕当前运营节点说一件具体的事，不写成培训课或工作命令。
```

硬性数量规则：

- 国内篮球短讯1—2条，国外篮球短讯1—2条，总新闻数2—4条；
- 国内至少1条为CBA/WCBA/NBL等职业联赛或中国男女篮、国家队新闻；
- 国内第2条可使用中国篮协青少年官方赛事，群众业余赛事最多1条且仅作低优先级补充；
- 国外优先NBA/WNBA，其次海外职业联赛和重要FIBA赛事；
- 机构提醒恰好 1 条，与当天新闻独立；
- 后台可以保留编辑备注，但群内不展示“今天可做”；
- 每条事实必须能回到来源、发布日期和原文链接。
- 最近7天已经出现过的同一新闻事件不得重复，即使更换标题或来源。

优先使用最近24小时内容；不足三条时可回看至最近72小时。超过72小时的旧闻、无关娱乐话题或未经核实的传言不得凑数。

## 三、选题范围

优先级从高到低：

1. 国内：CBA/WCBA/NBL、中国男女篮、国家队及中国篮协重要规则；
2. 国外：NBA/WNBA，海外职业联赛和重要FIBA赛事；
3. 国内补充：中国篮协、校园或青少年官方赛事；
4. 群众业余赛事只在没有更高优先级内容时少量补充。

热点只用于新闻筛选。机构提醒按日期和培训机构运营节奏确定，不为了关联而硬蹭新闻。

## 四、来源与事实核验

### 4.1 来源优先级

优先使用：

1. 官方赛事组织、政府部门、协会、联盟、学校或研究机构的原始发布；
2. 有编辑责任和署名机制的权威媒体；
3. 可追溯到原始数据、文件或完整采访的专业媒体。

社交媒体截图、自媒体转述、短视频口播、无署名聚合页和搜索摘要不能单独作为事实依据。它们可以提供线索，但发布前必须找到原始来源。

所有自动采集链接必须使用 HTTPS 并通过部署端来源域名白名单。白名单代表“允许进入核验流程”，不代表该来源的每句话都自动可信。

### 4.2 机构提醒依据

机构提醒不依赖当天新闻，而以项目已确认的篮球培训业务知识和当前日期为依据。系统按开学、寒暑假、续费、排课、教练交接、请假补课、家长反馈和赛事冲突等节点轮换主题。

提醒不得虚构行业数据、机构案例或普遍结论；只说明常见流程中可能出现的问题，并明确不同机构需要结合自身情况。

### 4.3 最小证据台账

每份晨报在生成阶段至少保存以下字段：

| 字段 | 要求 |
|---|---|
| 事实或数据 | 使用自己的话准确复述 |
| 来源名称 | 能辨认发布主体 |
| 原文链接 | HTTPS 且通过白名单 |
| 发布日期 | 与事件发生日期分开记录 |
| 统计对象和时间 | 数字必须有口径 |
| 能证明什么 | 写最窄结论 |
| 不能证明什么 | 标明证据边界 |
| 是否自行计算 | 写出基数和算法 |

无法核对人名、比分、日期、数字、规则原文或引语时，删除该细节，不能凭常识补齐。

## 五、机构提醒怎么写

机构提醒只处理一个具体问题。可以落在：

- 开学前后的课表确认和暑期班转常规班；
- 待续费家庭的时间确认与课包衔接；
- 新生、老生分班和训练基础差异；
- 教练排班、代课和班级交接；
- 请假补课、赛事与常规课冲突；
- 家长反馈、学员成长记录和训练强度调整。

开学前后的示例：

> 暑期班转常规班时，最容易反复的是上课时间。可以把未确认课表、待续费和请假补课分开列，家长问起来更清楚。

这类提醒点出角色和流程，但不声称所有机构都有同样问题。

## 六、机构提醒的语气

- 可以给出温和、具体的提醒，但不使用“必须、立即执行、抓住机会”等命令或营销语言。
- 不从赛事热度推导招生、续费或转介绍效果。
- 不在群里安排任务、清单、打卡或作业。
- 一至两句话说完，读者看完能继续聊天，而不是被上课。

## 七、语言与篇幅

正文使用简体中文，写具体的人、动作、时间和后果。优先短句，必要时用一两句解释机制。

禁止机械套话和夸大表述，包括但不限于：

- “不难发现”“值得注意的是”“综上所述”；
- “行业巨变”“全面爆发”“所有机构都”“史上最强”；
- 连续使用“趋势、逻辑、赋能、抓手、底层、闭环”等抽象词；
- 为制造金句而编排对仗、排比或无证据设问；
- 把相关性写成因果关系；
- 把自行计算的数字写成来源原话。

企微正文按 UTF-8 字节数计算，硬上限为 4000 字节，发布目标不超过 3600 字节。字节超限时按以下顺序压缩：

1. 删除重复背景；
2. 缩短不影响事实边界的赛讯描述；
3. 合并重复来源说明；
4. 删除修饰语。

不得截断数字、日期、原文链接、否定词或证据边界句。

## 八、禁止发布的内容

以下任一情况出现，整条晨报停止创建企微任务并进入人工复核：

- 虚构或无法核对的比分、人物、机构、政策、数据、采访、案例或引语；
- 用单一事件代表整个培训行业；
- 只有一个来源却生成机构趋势判断；
- 转载正文、长段摘抄或未获授权的图片；
- 对未成年人公开姓名、联系方式、学校、健康状况、住址等非必要信息；
- 未公开的客户信息、群聊内容、机构经营数据或内部文档；
- 对伤病、医疗、法律或财务问题作无资质结论；
- 通过恐惧、焦虑或家长攀比推动报名；
- 攻击运动员、教练、裁判、学校、机构或家长；
- 赛小蜂篮球产品广告、销售二维码、优惠信息或变相软文；
- 与篮球培训机构经营没有可解释关系的热点；
- 来源链接不在 HTTPS 白名单或跳转目标无法核对。

## 九、发布前编辑检查

编辑或自动校验器必须逐项回答：

- [ ] 国内、国外是否各有1—2条新闻？
- [ ] 国内是否至少有1条职业联赛或国家队新闻？
- [ ] 群众业余赛事是否最多1条且没有挤占职业/国家队内容？
- [ ] 每条赛讯的人名、赛事、比分、日期是否与原文一致？
- [ ] 机构提醒是否只处理一个当前运营问题？
- [ ] 机构提醒是否独立于新闻，没有硬做新闻分析？
- [ ] 是否写出了机构中的具体角色、流程、成本或风险？
- [ ] 机构提醒是否具体、自然，没有说教或营销口号？
- [ ] 是否删除了产品广告和硬蹭热点？
- [ ] 是否没有虚构数据、案例和引语？
- [ ] 是否保护客户与未成年人隐私？
- [ ] 所有链接是否为白名单内的 HTTPS 原文？
- [ ] 正文是否不超过 4000 UTF-8 字节，目标是否不超过 3600 字节？

任何一项无法确认时，不自动创建群发任务。低新闻量不是降低证据标准的理由；当天内容不足时应报告“可靠内容不足”，由运营人员决定是否暂停当日晨报。
