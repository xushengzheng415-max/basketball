# 赛小蜂篮球 2.1.4 版本更新记录

版本号：2.1.4
更新日期：2026年9月1日
更新类型：修复与体验优化
影响范围：小程序计分板、MC 音效设置、我的、云端语音服务
发布状态：待提交审核
验证结果：验证通过

## 用户可见更新

1、修复其他微信账号无法播放进攻、防守及部分比赛音效的问题。

2、恢复当前比分播报，男声、女声、童声三种音色均可正常使用。

3、MC 音色改为三枚直接单选按钮，点击即保存并试听。

4、“我的”页面显示当前版本并提供历次更新日志。

## 验证摘要

- 云存储现有 21 个公共 MC 音频文件均存在，读取规则已按公共音效只读、其他用户文件私有的边界生效。
- 标准女声、现场男声、童声三种比分播报均成功生成 MP3，临时地址读取状态为 HTTP 200。
- MC 音色直选行为检查通过，任何时刻仅一个音色选中，连续快速切换不会被旧请求覆盖。
- 项目根版本、依赖锁定根版本和“我的”页当前版本均为 2.1.4。

## 发布边界

本记录用于 2.1.4 审核前收口。微信审核通过前不得标记为正式上线，也不得启用 2.1.5 或创建 2.1.5 公开公告。
