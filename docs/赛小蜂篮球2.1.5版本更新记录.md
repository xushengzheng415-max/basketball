# 赛小蜂篮球 2.1.5 版本更新记录

版本号：2.1.5  
更新日期：2026年9月1日  
更新类型：功能新增与现场体验优化  
影响范围：裁判计分板、快速比赛、正式赛事、电视大屏、我的  
发布状态：提交审核中  
验证结果：技术验证通过，待现场联调

## 用户可见更新

1、正式赛事和首页快速比赛均可连接电视大屏。

2、裁判计分板新增“电视大屏”入口，可复制6位大屏码或完整链接。

3、电视大屏实时展示双方队徽、队名、比分、比赛时间、节次、球权、犯规、暂停和进攻时间。

4、大屏采用高对比电子比分牌样式，适配电视、投影仪和LED显示设备。

5、支持浏览器全屏、自动校时和断线重连。电视端保持只读，不影响裁判计分操作。

6、“我的”页面底部版本号和更新日志更新为2.1.5。

## 使用方法

1、从正式赛事或首页“开始快速比赛”进入横屏计分板。

2、点击顶部“电视大屏”，复制完整链接或记下6位大屏码。

3、在笔记本电脑或电视浏览器中打开 `https://www.sxfbasketball.cn/scoreboard.html`。

4、输入大屏码进入比赛。笔记本连接电视后，可按F11全屏显示。

## 验证摘要

- 大屏网页、样式、脚本及只读接口线上回读状态为HTTP 200。
- 1920×1080电视比例截图检查通过，无页面滚动、裁切或中轴挤压。
- 正式赛事大屏会话、快速比赛临时大屏会话及结束关闭逻辑通过专项契约检查。
