# 蜂狂篮球公众号战术动作图规范

## 固定视觉

- 同一篇文章中的战术图必须使用同一块球场模板，不得混用不同木地板、禁区配色、篮架或视角。
- 默认球场：浅色枫木地板、深灰黑场线、不填充禁区、白色页边背景。
- 默认视角：三分之四俯视半场；同组图片保持相同缩放、篮筐位置和边线比例。
- 进攻方统一黑橙球衣，防守方统一白色球衣；同一球员编号和肤色在连续图中尽量一致。
- 跑动路线用橙色箭头，传球路线用黑色实线箭头，阅读或球路提示可用黑色虚线。

## 使用规则

- 新闻现场使用真实官方或媒体照片；战术、动作分解可使用AI示意图。
- 每张AI图的图注必须明确标注“AI训练动作示意”，不得冒充比赛照片。
- 新图优先引用上一篇已确认的球场图作为风格参考，再生成同系列图片。
- 如必须使用全场图，也应沿用同一地板纹理、线条粗细、配色和人物画风。
- 同时包含案例复盘和训练方法时，案例图使用A/B/C编号，并严格统一为该场比赛双方的实际主色；训练图使用1/2/3编号及统一训练球衣。图注必须分别写明“AI案例回放示意”和“AI训练动作示意”。同一案例组内不得把一支球队画成两种不同颜色。
