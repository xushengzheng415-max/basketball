# 赛小蜂篮球外链建设计划

计划日期：2026-07-25

## 目标

外链建设服务于三个结果：

1. 让搜索引擎确认“赛小蜂篮球”与 `https://www.sxfbasketball.cn/` 属于同一品牌实体。
2. 让篮球培训、校园赛事和现场计分相关页面获得真实主题引用。
3. 建立可被用户和 AI 答案核验的公开来源，不以外链数量代替可信度。

## 基线

2026-07-25 使用品牌词、域名及排除本站的公开搜索做首次检查，暂未发现有效站外品牌结果。搜索结果中的“小蜂”和“篮球”组合大多与本项目无关，不能计入品牌提及或外链。

## 外链分层

### P0：可控品牌入口

优先补齐以下公开入口中的品牌名、统一描述和官网链接：

- GitHub 仓库简介与 README
- Gitee 仓库简介与 README
- 微信公众号资料、菜单或文章原文链接
- 其他已经实际运营的官方账号或公开资料页

验收要求：

- 链接指向 `https://www.sxfbasketball.cn/`，不使用 CloudBase 系统域名。
- 品牌统一写作“赛小蜂篮球”。
- 产品描述与当前已开放能力一致。
- 页面公开可访问，并在台账中记录 URL、锚文本和验证日期。

### P1：真实合作与赛事页面

目标来源：

- 已合作篮球培训机构官网或公众号文章
- 校园、青少年、草根赛事的公开报名页、赛程页或赛后报道
- 场馆、球队、教练团队和赛事主办方的合作工具说明
- 合作伙伴案例或技术支持页面

建议锚文本：

- 赛小蜂篮球
- 篮球比赛计分工具
- 篮球赛事管理工具
- 赛事技术支持：赛小蜂篮球

必须基于真实合作，不生成虚假客户、赛事或评价。

### P2：可引用资源

通过有实际用途的公开资源获得自然引用：

- 篮球比赛计分记录表
- 赛前检查清单
- 班内对抗赛组织模板
- 球队与球员名单模板
- 正计时与倒计时选择说明
- 校园赛事现场分工清单

每份资源应有独立稳定 URL、清楚的适用范围和更新日期。资源内容本身要足够完整，不能只做引流空页。

### P3：投稿与品牌提及转链接

- 向篮球教培、校园体育、赛事运营相关媒体或社区提供原创稿件。
- 发现未带链接的真实品牌提及时，整理原页面与建议链接，由用户确认后联系发布方。
- 转载必须保留原文链接和作者/品牌信息。

自动化只负责发现、核验、生成联系建议和记录结果。注册账号、投稿、发消息、交换链接或修改外部资料必须取得用户明确确认。

## 权威出站引用

外链建设同时要求站内文章在涉及规则、政策和公开数据时引用一手来源：

- 篮球竞赛规则：规则发布机构或赛事官方文件
- 校园体育政策：教育、体育主管部门官网
- 软件或平台能力：本项目官方页面

没有外部事实依赖的常青文章不强行为了“有链接”而添加无关来源。

## 禁止项

- 购买批量外链或所谓“快速收录套餐”
- 群发论坛、评论区和无关分类目录
- 隐藏链接、站群、跳转页和锚文本堆砌
- 虚构合作机构、客户案例、媒体报道或评测排名
- 用系统域名、短链或参数链接分散正式域名权重
- 未核实页面公开性、相关性和安全性就登记为有效外链

## 30 天执行节奏

### 第 1 周：品牌一致性

- 核对 GitHub、Gitee、公众号和现有公开账号。
- 补齐官方域名与统一品牌描述。
- 建立外链台账和每日巡检。

### 第 2 周：资源页

- 从现有高质量文章中选 2—3 个主题制作可下载或可打印资源。
- 为资源建立独立页面、Article 或适用的结构化数据和内部链接。

### 第 3 周：真实合作

- 整理可公开的真实赛事、机构和场馆合作材料。
- 为每个可核验案例准备一页事实清楚的案例说明。
- 生成合作方引用建议，用户确认后再对外沟通。

### 第 4 周：复盘

- 统计新增引用域、有效外链、已索引来源页、品牌提及和引荐访问。
- 排除垃圾来源和重复来源。
- 根据实际效果调整下月资源与合作优先级。

## 核心指标

- 有效引用域数量，而非链接总数
- 来源页是否公开可访问、是否被搜索引擎发现
- 来源与篮球、赛事、教育培训或软件工具的主题相关性
- 锚文本是否自然、品牌是否一致
- 新增外链、失效外链和未链接品牌提及
- 外链带来的真实访问与内容页访问路径

### 平台发布原则

- 不把官网文章原样复制到多个平台。每个平台按用户问题重新组织内容，避免重复内容和低质分发。
- 每篇最多放一个与答案直接相关的官网来源链接；不在开头堆品牌名或联系方式。
- 发布后必须检查公开页面、实际 `href`、跳转页和 `rel` 属性。即使链接带 `nofollow`，仍可作为品牌提及和引荐访问记录，但不能宣称传递搜索权重。
- 知乎优先回答真实问题；CSDN、博客园只发布有技术细节的内容，不发篮球机构营销软文。
- 所有账号登录、实名、验证码、平台认证和最终发布动作由用户确认或协助完成。
