## 第四阶段：体验版——三种邀请方式

[ ] T4-01 点击“邀请球队报名”后自动同步赛事并打开邀请面板。
[ ] T4-02 邀请面板同时显示微信分享、邀请海报和复制邀请码三种方式。
[ ] T4-03 转发给微信好友或群后，接收账号点击卡片进入正确赛事报名页。
[ ] T4-04 分享卡片标题包含正确的赛事名称。
[ ] T4-05 生成邀请海报后，海报包含赛事类型、名称、主办方、赛制、小程序码和邀请码。
[ ] T4-06 海报可以预览并保存到系统相册。
[ ] T4-07 首次拒绝相册权限后有明确提示，重新授权后可以保存。
[ ] T4-08 使用另一台手机扫描海报小程序码，进入正确赛事报名页。
[ ] T4-09 点击复制邀请码后，剪贴板内容仅为邀请码。
[ ] T4-10 赛事首页“已有赛事邀请码”可以输入邀请码并进入正确报名页。
[ ] T4-11 空邀请码、错误邀请码和已关闭邀请码均显示准确提示。
[ ] T4-12 微信卡片、海报扫码和邀请码进入的是同一个赛事报名记录。

## 第五阶段：体验版——报名与审核

[ ] T5-01 班班赛报名页自动显示赛事学校、学段和比赛年级。
[ ] T5-02 班班赛受邀方只需选择自己的班级，不重新选择赛事年级。
[ ] T5-03 受邀方已有对应班级队时自动复用并显示球员人数。
[ ] T5-04 受邀方没有班级队时自动创建并绑定班级队。
[ ] T5-05 同一个账号不能向同一赛事重复提交报名。
[ ] T5-06 同一个班级不能由不同账号重复报名。
[ ] T5-07 机构周赛报名页不出现学校、学段、年级和班级字段。
[ ] T5-08 机构周赛可以选择已有球队并提交报名。
[ ] T5-09 创建者能在球队页看到待审核报名及球员数量。
[ ] T5-10 点击通过后，球队进入正式参赛队列表。
[ ] T5-11 点击驳回后，球队不进入正式参赛队；受邀方可修改后重新提交。
[ ] T5-12 普通参赛账号看不到其他待审核球队的敏感资料。

## 第六阶段：体验版——赛制与对阵

[ ] T6-01 4队单循环生成3轮、6场，每两队只交手一次。
[ ] T6-02 5队单循环生成10场，每轮1队轮空且不生成虚假轮空比赛。
[ ] T6-03 4队双循环生成12场，每两队交手两次并交换主客场。
[ ] T6-04 8队分2组时，小组赛生成12场，每组4队单循环。
[ ] T6-05 小组赛未全部结束前不能生成淘汰赛。
[ ] T6-06 小组赛完成后按每组前2名生成4队淘汰赛。
[ ] T6-07 晋级球队总数不是2、4、8或16时阻止发布并给出提示。
[ ] T6-08 发布对阵前必须先显示预览和总场次数。
[ ] T6-09 未开赛场次可以交换主客队，刷新后结果保留。
[ ] T6-10 已开始或已结束场次不能交换主客队。
[ ] T6-11 比赛入口继续进入原有横屏计分板，没有新增另一套计分页面。

## 第七阶段：体验版——积分榜

[ ] T7-01 默认积分规则为胜2分、负1分、弃权0分。
[ ] T7-02 创建时修改积分规则后，赛事详情显示新规则。
[ ] T7-03 比赛结束后胜负场次、得失分、净胜分和积分计算正确。
[ ] T7-04 同积分时优先按相互战绩排序。
[ ] T7-05 相互战绩相同时按净胜分排序。
[ ] T7-06 净胜分相同时按总得分排序。
[ ] T7-07 全部条件相同时显示并列排名。
[ ] T7-08 小组赛分别显示各组积分榜，不混合计算。
