# 赛小蜂篮球知识库导航

本目录是代码仓库内供开发人员和 Codex 共同读取的正式知识库。开始修改前先读取相关规则，完成修改后同步开发记录和专题文档。

## 阅读优先级

1. 当前任务中用户的明确指令。
2. 根目录 `AGENTS.md` 的技术、安全、产品和部署红线。
3. `DEVELOPMENT_LOG.md` 中的当前状态与已验证事实。
4. 与当前模块对应的专题规则和原型。
5. 历史日志、发布公告和旧原型。

篮球和足球的账号、CloudBase 环境、云函数、版本和产品字段相互独立，不能跨项目复制配置。

## 主要专题

- 赛事中心：赛事创建、竞赛组别、抽签、赛程、报名、赛果和赛事运营。
- 裁判教练协同：主裁判、主客队教练、助教分工、战术板和数据提交。
- 现场计分：裁判横屏计分台、电视大屏、快速比赛和比赛状态同步。
- 教务系统：机构、校区、教练、学员、课程、班级、排课、课消和家长建档。
- 账号与权限：微信身份、机构成员关系、邀请、授权和数据边界。
- 官网与运营：官网文章、使用指南、AEO/GEO 与公开内容。
- 版本与发布：根目录 `DEVELOPMENT_LOG.md`、日期日志、发布公告和发布明细。

## 新文档规则

- 当前进度、验证和部署事实写入 `DEVELOPMENT_LOG.md` 或当日日志。
- 长期业务规则写入对应专题文档，并在开发日志说明变更原因。
- 原型、截图和素材必须放入明确的专题目录，不复制到多个临时位置。
- 历史文档要标明状态，不能覆盖当前确认规则。
- 中文文档使用 UTF-8，文件名使用清晰中文。

## 不纳入正式仓库的本地资料

以下内容默认留在本机或独立资料库，不作为开发代码源：浏览器配置、临时验证目录、构建产物、公众号草稿输出、演示数据、软著原始材料、重复知识库镜像和运营素材。需要共享其中某份资料时，先确认授权、版本有效性和个人信息边界，再单独整理进入 `docs/`。

## 敏感信息红线

知识库不得保存密码、验证码、Token、Secret、API Key、支付密钥、生产数据库导出、身份证信息或未授权的真实用户资料。配置文档只记录变量名、配置位置、责任人和验收方式。
