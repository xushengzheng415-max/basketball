## 已确定的产品原则

1. 报名与资格是球队入驻、认领、审核的唯一入口；球队管理只展示已认领且审核通过的正式参赛队。
2. 仅球队模式隐藏球员档案；球队+球员模式才展示球员档案、资格审核和正式名单。
3. 抽签、赛程、导出均只读取审核通过的参赛名单。
4. 赛程是全赛事、全组别统一资源排程；组别如 U8、U10 是赛事组别，A/B 只是该组的小组，不应在全局筛选里被当作独立赛事组别。
5. 同一球队同一时段不可重复比赛；默认体力约束为成人单日最多上午一场、下午一场，青少年不得在同一上午连续两场。
6. 关键场次（半决赛、三四名、决赛）默认单场单场地进行；小组赛可并行。需要并行时由运营人员在日历里拖拽或增加时段调整。
7. 现场人员：裁判名单先建立并按场次分配主裁判。主队、客队提交首发与替补名单后，现场数据管理员一键启动系统；主裁判只核对场次并接管比分、时间和 MC。原数据统计任务分别交由双方主教练管理，主教练可通过通知或二维码分发给最多 5 名助教。
8. 后台补录比分可直接生效；现场回传比分才需要后台点击“复核”。未录入比分不得显示“已复核”。

## 当前已实现并已人工测试过的主要模块

### 1. 报名、球队、抽签

- 已有认领、审核通过、免审核/审核流与后续名单联动逻辑。
- 球队管理为报名数据的正式参赛视图；支持筛选、详情和资料关系查看。
- 海报导出支持按分组数量调节队名/队徽尺寸，队号在队徽前。

### 2. 赛程与场次

- 主入口为“赛程日历”，设置页降级为前置资源设置页。
- 支持场馆、场地、半场 A/B、日期与上午/下午/可选晚间时段配置；每日开赛时段可调、可增。
- 日历支持拖拽至空场位或与已有场次交换；空时段可添加场次；没有比赛的时间段可删除。
- 场次列表已改为“竞赛日程”，可筛选、导出、打印，并支持 A4 竖/横版预览。
- 竞赛日程中淘汰赛对阵文案已改为：
  - 半决赛：A组第一 vs B组第二、B组第一 vs A组第二；
  - 三四名：场序13负者 vs 场序14负者；
  - 决赛：场序13胜者 vs 场序14胜者。

### 3. 现场执行

- 导航顺序：裁判名单、人员与任务、控制台状态；球员数据任务当前被隐藏。
- 裁判名单支持新增、编辑、删除、岗位多选以及查看当前可安排任务。
- 人员与任务从赛程自动生成场次任务，支持主裁判分配及单人/多人现场协作模式。后续需为每场自动生成主队、客队两份教练数据统计任务。
- 控制台状态改为模拟的现场连接与实时比分监控，可查看每场地/场次的比分状态。

> 简化启动边界：PC 只检查“主裁判已确定、主队名单已提交、客队名单已提交”，满足后由数据管理员点击一次启动。助教权限属于球队内部配置，不挂在主裁判或数据管理员页面。

> 2026-08-19 新基线：主裁判赛后对双方教练提交的数据分别执行“确认发布 / 退回修改 / 拒绝数据请求”。通过的数据进入平台统一数据库并按球队权限展示；主办方可查询，但不得作为官方 MVP 等个人奖项的自动评选依据。

### 4. 赛果与数据

- “赛果与复核”为第一个页面，展示全部场次，可用下拉快速定位场次；比分置于两队名称中间，未录入为 `- : -`。
- 淘汰赛场次随赛果列表显示，不再单独放在赛果模块下方。
- “积分与球队”根据赛制展示小组积分榜、赛果矩阵与淘汰赛晋级图；淘汰赛晋级图应继续向标准蛇形对阵图优化。
- 录入或修改比分后，积分榜/矩阵应即时重新计算；页面重新渲染后应保留到原场次滚动位置。
- 战报功能需支持按日导出多种海报款式，且可配置二维码，引导扫码关注服务号。

## 已知重点待验收/下一步

1. **淘汰赛晋级图视觉**：用户要求类似 NBA 季后赛的蛇形对阵关系，不要普通卡片堆叠。需要核验连线、胜负者流向与移动端/窄屏溢出。
2. **赛果矩阵对角线**：对角格应为从左上到右下的连续斜线，仅覆盖数据矩阵，不应反向或越过表头/行名。
3. **积分联动**：每次录入、修改、复核比分后，确认小组积分、赛果矩阵和淘汰赛对阵都按已生效比分更新；未录入场次无积分和复核状态。
4. **赛程可行性提醒**：当单日两场限制导致“小组赛未结束即安排半决赛”时，自动排赛必须阻止或提示。建议给出“增加第 3 天”与“开启晚间时段”两个可执行选项；不能默认硬排不合理赛程。
5. **竞赛日程导出一致性**：导出的 Excel 与页面 A4 预览目前结构接近但存在样式差异。目标是字段顺序、合并单元格、序号、日期/轮次分组、场馆/场地文案和排版一致；打印按钮须真实触发浏览器打印。
6. **页面回弹**：任何保存、录入比分、拖拽日历或筛选更新都不应强制跳回页面顶部，应停留在用户当前上下文。

## 推荐验收顺序

1. 先在报名与资格确认 8 支队伍均“已认领 + 已通过”。
2. 检查抽签分组与球队管理是否只出现正式队伍。
3. 在赛程设置修改比赛日期、场地和开赛时间，核验资源摘要实时变化。
4. 自动排赛后，重点检查球队体力限制、关键场次单场地、淘汰赛不早于小组赛完成。
5. 进入竞赛日程，切换横/竖版、导出和打印，核验输出一致。
6. 进入现场执行，以自建裁判名单完成一场单人模式和一场三人模式人员分配。
7. 在赛果与复核中录入几场小组赛比分，复核现场回传比分；回到积分与球队检查积分榜、矩阵与淘汰赛图同步。
