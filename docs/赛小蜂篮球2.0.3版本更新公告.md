# 赛小蜂篮球 2.0.3 版本更新公告

> 版本号：2.0.3
>
> 发布日期：2026-07-27
>
> 发布阶段：正式版

## 本次更新

### 小程序新版本提示

小程序发现新版本并完成下载后，会主动提示“发现新版本”。用户可自行选择：

1. 立即更新：重启小程序后进入最新版本。
2. 稍后：继续当前使用，不会被自动中断。

此次优化解决正式版发布后部分用户仍停留在旧版本的问题，无需再通过删除或重新关注小程序来获取更新。

## 使用说明

- 计分或其他现场操作过程中，小程序不会自动重启。
- 建议在比赛间隙或方便时点击“立即更新”，完成版本切换。
- 新版本的发布仍以微信小程序正式版发布为准。

## 体验与反馈

如在更新、计分或赛事使用过程中遇到问题，请通过赛小蜂篮球客服与我们联系，并说明手机型号、微信版本和问题发生时间，便于我们尽快处理。
