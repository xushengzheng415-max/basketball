# 裁判—双方主教练运行流程与数据面板衔接说明

> 阶段：原型设计基线
> 日期：2026-08-19
> 原则：先确认完整链路和原型，再进入正式页面开发

## 一、三个现场工作面

1. **主裁判控制台**：唯一写入官方比分、比赛时间、节次、暂停、球队犯规、球权、比赛结束和 MC 播放状态。
2. **主队教练团队**：主教练是数据总负责人，可亲自记录或把任务分给最多 5 名助理教练；团队只读官方比赛状态，只写主队数据；主教练平板端同时提供球队私有战术板。
3. **客队教练团队**：权限与主队对称，主教练同样可邀请最多 5 名助教，只能处理客队数据和客队私有战术内容。

主办方 PC 不参与现场高频操作，只负责赛前配置、任务分配、在线状态监控和赛后查询审计。

## 二、页面衔接

### 赛前

```text
PC 创建场次并确定主裁判
→ 主队、客队分别递交首发与替补名单
→ 现场数据管理员确认“主裁判 + 主队名单 + 客队名单”三项完成
→ 数据管理员一键启动本场现场系统
→ 主裁判核对双方球队、时间和场地后直接进入控制台
→ 双方主教练进入各自球队页面
→ 主教练在比赛前选择按数据分工或按球员分工
→ 选择教练，再选择该教练负责的数据或球员
→ 通过服务号通知、邀请链接或现场二维码发送权限
→ 助理教练点击通知或扫码确认本人任务后进入操作页
```

裁判端不配置球队名单、助理教练、统计口径或其他球队内部参数。数据管理员也只负责启动，不介入双方球队内部权限。

### 比赛中

```text
裁判修改官方比分/时间/节次
→ 统一事件流生成新状态快照
→ 双方教练顶部比分条只读刷新
→ 主教练或助理教练只在各自“球员×指标”范围内记录
→ 事件实时汇总到主教练任务监控面板
→ 系统持续检查重复负责人、未分配范围和设备同步状态
→ 选择完整得分归属时，球员得分合计与官方比分持续对账
```

教练在平板点击“战术板”时：

```text
数据录入页
→ 自动带入当前场上 5 人
→ 打开球队私有战术板
→ 画路线、摆球员、保存战术
→ 点击“返回数据录入”回到原球员和原比赛上下文
```

战术板不写入比赛事件流，不影响比分、球员统计或裁判核验。

### 赛后

```text
裁判结束比赛并确认官方赛果
→ 教练端冻结比赛中输入并进入提交检查
→ 系统检查得分一致、名单、重复事件和异常集中
→ 助理教练完成专项记录并提交给本队主教练
→ 双方主教练分别确认整队汇总版本
→ 完整球员得分归属由裁判强一致核验；自选/部分统计只确认口径和明显异常
→ 裁判分别确认发布、退回主教练或拒绝数据请求
→ 通过版本进入统一数据库
→ 按主队/客队权限展示在对应球队数据视图
```

一队未提交、被退回或被拒绝，不影响另一队，也不影响官方赛果和积分。

## 三、实时数据面板衔接

| 数据 | 写入端 | 读取端 | 冲突原则 |
|---|---|---|---|
| 官方比分、时间、节次 | 主裁判 | 双方教练、PC 主办方 | 裁判端唯一权威 |
| 暂停、球队犯规、球权 | 主裁判 | 双方教练、PC 主办方 | 裁判端唯一权威 |
| MC 播放状态 | 主裁判 | 主办方仅看运行状态 | 不影响比赛统计 |
| 主队球员数据 | 主队主教练与获授权助教 | 主队、适用范围内的裁判核验、授权主办方 | 客队不可见不可改；主教练负责整队汇总 |
| 客队球员数据 | 客队主教练与获授权助教 | 客队、适用范围内的裁判核验、授权主办方 | 主队不可见不可改；主教练负责整队汇总 |
| 战术板与战术库 | 各自主教练 | 本队授权教练 | 不进入赛事数据与裁判核验 |
| 核验状态 | 主裁判 | 对应教练、PC、球队数据视图 | 主客队分别处理 |

## 四、原型验收重点

1. 裁判端不出现球员数据录入入口。
2. 比分、时间、节次和 MC 在裁判横屏首屏内完成，不需要滚动。
3. 教练端始终显示只读官方比分和同步状态。
4. 教练端选择球员后，得分和技术统计按钮位置稳定、适合连续点击。
5. 战术板与数据录入一键往返，不丢失已选球员和比赛上下文。
6. 战术板明确标注球队私有，不进入官方数据。
7. 赛后两队分别提交、分别核验、分别发布。
8. 得分不一致时禁止直接确认；异常集中只提示，不自动判定作弊。
9. 核验后的球队数据页展示来源、核验人、版本和奖项禁用说明。

### 设备适配

- 主教练和助教使用手机或PAD时进入同一功能页面，只根据屏幕宽度改变分栏、滚动、折叠或分页方式。
- 手机与PAD的数据项、按钮、阵容、事件、任务、战术和汇总能力必须一致，不能因屏幕较小删除功能。
- 战术板统一使用指定球场底图；本方以头像识别，对方以圆形号码识别。
- 战术板在手机和PAD上均尽量全屏，完整工具以悬浮条叠加在球场上。

## 五、教练团队数据任务模型

每条可写任务由三部分组成：

```text
统计项目范围 × 球员范围 × 负责人
```

- 统计项目范围可以是进攻、防守、投篮，也可以只选择罚球得分、两分得分、三分得分等少量项目。
- 球员范围可以是全队、场上球员或自定义球员组。
- 负责人可以是主教练本人或最多 5 名助理教练之一。
- 同一场比赛每队最多有 6 名实际记录人：主教练 + 5 名助理教练。
- 同一“球员×指标”默认只能有一个主负责人；重复覆盖必须先消除，才能开始记录。
- 主教练必须在赛前完成权限分配。比赛开始后分工自动锁定，只能查看进度，不能新增、收回、转交或重新分配。
- 助理教练只可撤销和修正本人产生的事件，不能直接修改其他记录人的数据。
- 所有助理教练先提交给主教练，由主教练形成整队汇总版本并承担最终责任。

### 统计口径与完整性

- 主教练可以只统计本场需要的数据，不要求强制记录全部技术指标。
- 未选择的指标在结果页显示“未统计”，不能显示为 0，也不能参与跨比赛完整排名。
- 若选择“完整球员得分归属”，罚球、两分和三分归属必须覆盖全场，并与官方比分一致。
- 若只选择部分得分或部分球员，系统标记为“部分统计”，不强制与官方总比分相等。
- 裁判只对完整得分归属做强一致核验；篮板、助攻、投篮等球队自选数据由主教练内部确认，裁判只处理明显异常或争议。
