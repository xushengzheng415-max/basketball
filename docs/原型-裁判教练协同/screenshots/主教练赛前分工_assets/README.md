# 主教练赛前分工原型拆解说明

源图：11-主教练统计口径与技能分工.png  
尺寸：1600 × 900

## 页面结构

- 顶部为当前对阵、比赛阶段、实时同步状态和主教练身份。
- PAD 横屏采用左侧人员与分工方式、中部任务分配、右侧状态与完成操作三栏结构。
- 手机横屏保留相同功能，通过压缩栏宽、横向工作面和必要滚动适配，不删减任务。
- 页面流程固定为：选择记录方式 → 添加助教 → 分配数据或球员 → 完成分工并自动通知。

## 交互与状态

- 主教练可选择“我自己记”“分给助教”“本场不记录”。
- 选择助教协作后先添加本场人员；已有球队教练可直接加入，临时助教以微信好友或群分享为主。
- 分工只保留按数据和按球员两种主模式；先选教练，再点击可分配项直接保存。
- 绿色为可分配，灰色为已分配并显示负责人；不设置额外“选择中”状态。
- 完成分工后系统自动通知已加入助教；待接受人员接受最初邀请后自动获得对应权限，不再二次扫码。

## 数据字段

- matchId、teamId、teamScope、phase、syncStatus。
- headCoachUserId、assistantUserId、assistantStatus。
- assignmentMode、metricKeys、playerIds、assignmentVersion。
- rosterStatus、lockedAt、notifiedAt、updatedAt。

## 素材决策

- 页面顶栏、三栏面板、状态标签、教练列表、数据按钮和球员按钮全部使用 WXML/WXSS 动态渲染。
- 不从原型截图裁切任何生产按钮、文字、卡片或微信胶囊。
- 不新增页面级图标与底部导航；返回按钮与微信胶囊使用平台原生能力。

## 素材缺口

- 无新增生产图片。
- 助教微信身份头像优先读取真实头像；缺失时使用姓名首字占位。
- 网络失败、权限冲突和分工版本冲突使用代码状态呈现。

## 开发边界

- 正式目标路由为 native-dist/pages/match-coach-workspace。
- 任务中心进入该路由时必须携带真实 matchId 与球队范围。
- 主裁判既有控制台不改；主客队数据严格隔离。
- 比赛开始后分工锁定，只允许查看协作进度，不允许重新分配。
