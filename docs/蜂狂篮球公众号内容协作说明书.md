## 3. 阶段 A：每天交付什么

### 研究与证据

- 搜索最近 30 天、优先最近 7 天的青少年篮球、校园/青少年赛事、体育培训、非学科教培、家长沟通、招生续费、训练安全、监管执法等事件。
- 用户临时提出的事件只是待核验线索；每项使用事件至少要有 2 个独立可靠来源。优先政府/教育体育主管部门、法院、赛事主办方、当事机构公开回应、主流媒体。
- 对每项事件记录日期、地点、涉事主体、已确认事实、尚未确认内容、可讨论的篮球教培关联、事实/法律风险和来源链接。
- 短视频、微博、知乎、小红书评论、营销号转述不能作为确定事实或唯一依据。

### 数据与同行样本

- 先检查本账号历史文章、公开链接、后台数据或五个平台导出的 CSV/XLSX；原始导出只读，绝不覆盖。
- 缺失指标留空，绝不补 0 或猜测；仅比较同平台、同统计窗口、同主题的已核验文章。
- 同行样本尽力记录账号、完整标题、`mp.weixin.qq.com` 原文、发布日期、可见传播信号及证据边界。
- 没有可核验传播数据时只能叫“内容样本”，不能叫“爆款”。只有至少 5 篇样本同时有“公众号原文 + 可核验传播信号”，才可额外写爆款复盘；否则须写“未形成爆款结论”。

## 4. 阶段 B：行业主文标准

- 读者为篮球培训机构创始人、校长、运营/教务负责人、教练负责人和一线教练。
- 1200—2000 字；从真实经营或教学矛盾切入，给出判断、原因、常见误区和可执行动作。
- 优先主题：招生转化、续费流失、家长沟通、课程产品、教练培养、校区经营、赛事活动、学员成长、安全管理、机构口碑。
- 不虚构机构、人物、数据、采访原话、政策或经营成果；资料不足时收窄表达。
- 完成事实、时效、数字、标题一致性、读者价值、原创性、重复度和手机排版检查后，再做去模板腔编辑。

## 6. 微信草稿工具与本机配置

工具文件：[wechat-draft.js](E:\Documents\sxf-basketball\tools\wechat-official\wechat-draft.js)。阶段 B 验收通过后才可使用：

```powershell
node tools/wechat-official/wechat-draft.js doctor
node tools/wechat-official/wechat-draft.js published --offset 0 --count 20
node tools/wechat-official/wechat-draft.js materials --type image --offset 0 --count 20
node tools/wechat-official/wechat-draft.js draft --input <最终JSON路径> --cover <封面路径>
```

`draft` 只写草稿箱；不得自动群发或发布。默认本机配置为 `E:\Documents\sxf-basketball\tools\wechat-official\.env.local`，也可由 `WECHAT_ENV_FILE` 指向其他本机文件。可说明变量名及用途，但绝不能提供值：

| 变量名 | 用途 |
| --- | --- |
| `WECHAT_APP_ID` / `WECHAT_APP_SECRET` | 微信公众号 API 鉴权 |
| `WECHAT_THUMB_MEDIA_ID` | 默认封面素材标识 |
| `WECHAT_CACHE_FILE` | 本地缓存位置 |
| `WECHAT_ENV_FILE` | 指定本机环境文件 |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` | 可选本地模型配置 |
| `OPENAI_REASONING_EFFORT` / `ARTICLE_AUTHOR` | 推理参数与作者显示名 |
