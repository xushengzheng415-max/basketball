# 赛事中心一级页面原型与素材包映射

## 固定壳层

赛事中心所有一级页面统一复用以下壳层，不再随单页确认稿调整：

- 侧栏展开宽度：`311px`
- 页首高度：`116px`
- 内容左边距：`28px`
- 内容右边距：`26px`
- 侧栏与页首固定；二级标签栏固定在页首下方
- 侧栏主动收起时宽度为 `86px`

部分早期确认稿使用旧侧栏或旧页首。素材包保留旧壳层切片用于识别来源，但正式实现只拆解右侧业务内容，固定壳层优先。

## 第一批开发边界

- 本批只实现七个一级模块的默认入口页面。
- 同模块的其他二级页面继续保留现有演示能力，但不在本批进行高保真重构。
- 一级页面已完成；下一阶段按业务顺序处理各模块其余二级页面。
- 所有业务图片、赛事Logo、队徽和二维码必须来自真实业务上传或动态生成，不从确认稿裁切。
- 普通文字、按钮、卡片、表格、状态、进度条、开关和图表均使用代码实现。

## 推荐实现顺序

1. 赛事管理 · 赛事空间
2. 报名与资格 · 入驻进度
3. 球队与球员 · 球队库
4. 抽签与分组 · 小组赛及晋级
5. 赛程与场次 · 自动排赛
6. 现场执行 · 人员与任务
7. 赛果与数据 · 赛果复核

该顺序对应赛事从创建、入驻、球队关系、分组、排赛、现场安排到赛果审核的完整主办方流程。
