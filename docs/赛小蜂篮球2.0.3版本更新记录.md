## 本次更新

### 小程序版本更新提示

小程序发现新版本并完成下载后，将主动提示“发现新版本”。用户可选择：

- 立即更新：小程序重启后进入最新版本。
- 稍后：继续当前使用，不会被自动中断。

该机制解决正式版发布后部分用户仍停留在旧代码包的问题，不再需要通过删除或重新关注小程序来获取最新版本。

## 使用说明

- 计分或其他现场操作过程中不会自动重启小程序。
- 用户可在方便时点击“立即更新”完成版本切换。
- 发布时仍需在微信小程序后台完成正式版发布；开发版和体验版不等同于正式版。
