# 麦步赛事公众号内容规则

> 注：麦步赛事为成人体育赛事服务公众号，聚焦企业运动会、趣味运动会、健步走、马拉松、自行车赛及篮球/乒乓球/羽毛球等大众赛事的策划、执行、保障与工具。当前以"麦步赛事"为唯一品牌标识。

## 内容范围与栏目状态

* 日常内容只产出一篇面向赛事人（办赛执行者）的**行业主文**；不再采用"双篇组合"。

* 常规选题不宣传赛小蜂篮球产品、功能、版本或品牌。行业主文以行业价值为主体，正文结束后、资料来源前可保留一次赛小蜂篮球首页原生小程序卡片作为服务入口。

## 自动化选题门禁（最高优先级）

每日自动化必须分为两个阶段；任何无人确认的运行都不得从检索直接跳到成稿。

### 阶段 A：媒体事件雷达与候选提交

1. 先复盘本账号历史数据，再搜索最近 30 天、优先最近 7 天的成人体育赛事与大众参与型活动媒体事件：企业运动会、趣味运动会、健步走、马拉松、自行车赛、篮球/乒乓球/羽毛球等球类赛事的策划、执行、安全、保障、工具与行业趋势。用户提出的事件只能作待核验线索。
2. 每项事件至少核验两项独立可靠来源，优先政府部门、教育/体育主管部门、法院、主流媒体、赛事组织方与当事机构公开回应；记录已确认事实、未确认内容、行业关联与事实/法律风险。
3. 同步调研近 3 个月同行微信公众号文章，尽力记录账号、完整标题、`mp.weixin.qq.com` 原文、发布日期、可见传播信号与证据边界。没有可核验传播数据时只称"内容样本"，不得称"爆款"。
4. 每日必须提交 3 个待讨论候选：关联事件、现实矛盾、目标读者、两项以上可靠来源、历史文章差异、独立创新点、唯一中心论点、可讨论问题、风险与证据等级。公众号样本不足时仍须交付候选，但不得下爆款结论。
5. 只有 5 篇同行公众号文章同时具备原文与可核验传播信号，才可额外总结爆款共同特征、爆款路径及推荐顺序；不得跨平台比较绝对阅读量，单篇高数据只作线索。
6. 阶段 A 完成后等待用户在**本轮**明确选题。用户选题前，禁止写正文、禁止调用 ImageGen、禁止制作图片、禁止生成最终 JSON 或写入草稿箱。

### 阶段 B：用户选题后的行业主文制作

1. 只有用户在收到本轮候选后明确选择题目，才开始行业主文。自动推荐第一名、历史默认题、上次选题和热点本身均不算确认。
2. 先完成证据台账、正文与严格审校；通过后才制作或整理图片。
3. 完成事实、时效、计算、标题正文一致性、读者价值、原创性、重复度和手机排版检查，再做去模板腔编辑；硬性检查失败不得入草稿箱。
4. 最后完成排版、单篇 JSON、公众号草稿箱、跨平台归档和数据复盘。

## 行业主文规格

* 面向赛事人：办赛执行者、企业赛事/工会活动策划、赛事服务从业者、体育场馆与社群运营者。

* 长度 1200—2000 字，从经营或教学管理中的具体矛盾切入，提供清晰判断、原因拆解、常见误区和可执行建议。

* 优先方向：企业/趣味运动会策划、健步走与路跑组织、自行车赛办赛、球类赛事执行、赛事安全保障（医疗/AED/保险）、报名/计时/摄影直播等工具、志愿者与裁判管理、赛事传播与降本增效、赛事服务经营与口碑。

* 不虚构人物、机构、数据、采访原话、政策或经营成果；资料不足时明确收窄表达，不把推测写成事实。

* 标题有判断和现场感，拒绝夸张标题党、空泛成功学及"首先、其次、最后"式模板文。

## 前期内容策略（流量冷启动）：共鸣优先 + 转发钩子

- 账号当前流量少，前期（冷启动期）内容以「赛事人共鸣」为第一优先级：目标是引发同行主动转发、把精准读者沉淀进社群，而不是追泛爆款。
- 共鸣类选题优先方向：替赛事人说话的观点文（甲方无理要求、赛事人辛苦、被低估）、踩坑/行业内幕（安全红线、被坑经历、低价中标）、实用清单/模板（避坑 N 条、执行 Checklist），同行易收藏转发。
- 守边界：共鸣文仍是「赛事人视角」，不滑向泛鸡汤、八卦或标题党；引来的是可进社群的精准赛事人，而非泛体育围观者。
- 每篇文末、立牌之前固定加一句「转发钩子」引导转发（如「如果你是做赛事的，转给同行看看」），与立牌形成「阅读→转发→进群」闭环。
- 待积累稳定精准粉丝后，再逐步加大政策解读与深度行业文比重。
