## 页面结构

- 生产页面继续使用赛事中心PC壳层、顶部赛事选择和“赛程日历 / 竞赛日程”二级导航。
- 主内容改为正式白底竞赛日程单据；上方居中显示赛事名称与“竞赛日程”，辅助展示当前场馆及数据范围。
- 表格列固定为日期、时间、轮次、组别、比赛队、场地、序号。
- 相邻且相同的日期、轮次纵向合并；数据按日期、时间、场地排序。

## 交互与状态

- 复用现有阶段、轮次、组别、球队、场地、状态筛选。
- 导出与打印读取筛选后的同一份竞赛日程数据。
- 空状态显示“暂无符合条件的竞赛日程”，不输出假数据。

## 数据字段

- 日期、时间来自 `scheduleRows[].time`。
- 轮次来自 `round`，阶段信息保留在筛选与必要的辅助信息中。
- 组别优先显示完整 `group`（包含 A组/B组）。
- 比赛队由 `home`、`away` 组成；场地来自 `venue`；序号采用当前正式场次编号的数字部分或排序号。

## 素材决策

- 源图仅作为结构、列宽、表格密度和合并单元格参考。
- 标题、表格、文字、边框和按钮全部使用代码渲染，不使用截图裁切作为生产素材。
- 无新增图标；导出、打印沿用项目共享图标。

## 素材缺口

- 无生产图片缺口；真实赛事名称、场馆、球队和赛程由业务数据提供。

## 开发边界

- 不改变赛程日历和 `scheduleRows` 唯一数据源。
- 不删除筛选、导出、打印能力。
- 本参考图为用户本轮明确指定的格式，素材包状态已批准，可进入正式实现。
