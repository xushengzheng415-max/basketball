## 机构端当前能力

- 经营驾驶舱：实收、课消、在读学员、续费风险、今日课程与待办。
- 教务管理：课程、班级、课表、计划、点名和课后评价入口。
- 学员管理：学员档案、课包、出勤、评价和续费状态。
- 教练管理：教练档案、排课负荷、课时与教学质量。
- 赛事中心：独立八项侧边栏，包含赛事工作台、赛事管理、报名与资格、抽签与分组、球队与球员、赛程与场次、现场执行、赛果与数据；支持自动排赛、多组别统一日历、技术台三席绑定、赛果复核和球员数据包分账。
- 服务号协同：演示外请人员手机号核验、任务接受与场次权限绑定，以及家长补全球员资料、自愿购买数据包和查看报告的完整路径。
- 数据报表、财务中心和机构设置。

当前机构端为 PC 交互原型，使用演示数据；后续需要接入机构身份、权限与云端数据接口。

## 机构账号与登录

- `admin/index.html` 为机构用户登录注册入口，手机号验证码登录与注册合并为一个流程。
- 新手机号验证成功后自动创建机构免费赛事账号和一个“默认校区”，首次进入赛事工作台；机构名称与 Logo 后续在后台补充。
- 已注册手机号验证成功后恢复原机构归属与权限，不重复创建机构。
- 同一可信设备的登录状态固定保留 30 天；到期、主动退出或风险验证时才重新验证手机号。
- 连续 30 分钟无操作进入四位锁屏，解锁不发送短信；连续输错 5 次限制输入 60 秒，但不清除 30 天登录状态。
- 当前交互验收验证码固定为 `123456`，短信发送和校验已封装为可替换接口；正式接入后应使用安全 Cookie 保存服务端会话。
- `admin/platform-ops.html` 继续作为平台运营人员独立入口，不开放机构用户注册。
- 新注册机构完成四位锁屏密码设置后进入独立赛事工作台；经营后台的“赛事中心”按钮同样跳转到该工作台。
- 赛事中心继续复用 30 天可信设备会话和 30 分钟四位锁屏；`?demo=1` 仅作为外部演示免登录参数。

## PC 后台图标库

- 通用图标位于 `admin/assets/icons/pc-common/`。
- 当前 PC 缺失语义统一采用 Lucide 官方 SVG，并保留 ISC/MIT 许可文本与语义映射。
- 页面不使用 Emoji、字符或 CSS 路径冒充功能图标；机构 Logo、赛事 Logo 和队徽属于独立上传素材，不纳入图标库。

## 赛事中心固定壳层规范

- 赛事中心所有页面统一复用同一个侧栏和页首，不允许在单独业务页重新定义壳层尺寸。
- 展开状态侧栏宽度固定为 `311px`，页首高度固定为 `116px`。
- 页首左、右内边距固定为 `38px`、`32px`。
- 右侧业务内容相对工作区的左、右边距固定为 `28px`、`26px`。
- 侧栏和页首在页面滚动时保持固定；二级标签栏固定在页首下方。
- 工作台、赛事管理、报名资格、抽签分组、球队球员、赛程场次、现场执行和赛果数据只能调整右侧业务内容，不得因页面差异移动页首、侧栏或内容起点。
- 用户主动点击“收起菜单”时，侧栏可收窄至 `86px`；这是唯一允许改变侧栏宽度的交互状态。

## 平台运营工具能力

- 数据概览：用户、反馈、订单、权益、会员码、赛果。
- 用户资料：查看昵称、授权标识、手机号、来源。
- 反馈信息：查看用户提交的建议、问题和合作信息。
- 会员码：调用 `sxCreateRedeemCode` 生成测试会员码。
- MC 音乐库：调用 `sxSaveAudioLibrary` 保存云存储音频 fileID，小程序计分盘通过 `sxGetAudioLibrary` 自动同步。

## 使用前配置

在页面顶部填写：

- 云函数 HTTP 网关域名，例如 `https://xxx.app.tcloudbase.com`
- 后台口令 `SXF_ADMIN_TOKEN`

上线前建议在下面两个云函数里配置同一个 `SXF_ADMIN_TOKEN` 环境变量：

- `sxCreateRedeemCode`
- `sxSaveAudioLibrary`

如果暂时不配置口令，函数会允许调用，但只适合开发测试。

## 绑定 sxfbasketball.cn

推荐把 `sxfbasketball.cn` 或 `admin.sxfbasketball.cn` 指向云开发静态网站托管：

1. 在云开发控制台打开“静态网站托管”。
2. 上传 `admin/` 目录里的文件。
3. 在“自定义域名”里绑定 `sxfbasketball.cn` 或 `admin.sxfbasketball.cn`。
4. 按控制台提示到域名 DNS 添加 CNAME 解析。
5. 等 HTTPS 证书签发完成后，用 `https://sxfbasketball.cn` 访问后台。

更推荐使用 `admin.sxfbasketball.cn` 做后台域名，主域名 `sxfbasketball.cn` 后面还能留给官网或下载介绍页。

## 机构后台简易交互模型

本地启动：

```powershell
npm run admin:serve
```

访问：

`http://localhost:5174/机构后台简易交互模型.html`

模型用于确认服务号开户注册、赛事中心默认开通、手机号验证码登录、四位锁屏和点击式新手引导；机构后台已提供工作台、赛事中心、员工与权限、课包与收款、排课管理、经营管理、数据报表、模块与设置的简易可点击页面。模型不连接真实短信、授权码、支付或云端数据。
