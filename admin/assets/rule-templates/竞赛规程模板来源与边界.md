# 竞赛规程模板来源与边界

## 模板来源

本项目的竞赛规程生成器参考了用户提供的三份正式赛事资料：

1. 《2025 年中国小篮球系列活动·全国总决赛竞赛规程》
2. 《2025-2026 赛季 NYBO 青少年篮球公开赛公开组竞赛规程》
3. 《2025-2026 赛季 NYBO 青少年篮球公开赛精英组竞赛规程》
4. 《2025-2026 赛季世界青少年联合运动会（UWG）中国区选拔赛竞赛规程》

这些文件只用于分析正式规程的章节组织、条款颗粒度、参数表结构和附件类型。系统模板不复制原赛事名称、赞助商、主办单位、报名平台、收费标准、全国总决赛资格或其他品牌专属制度。

合并时执行“只补缺项”原则：已有模板与参考资料都包含的内容保持不变；已有模板独有内容不删除、不替换；仅将参考资料中对普遍办赛有价值、且当前模板未覆盖的条款做中性化补充。

## 已形成的模板

### 篮球赛事通用竞赛规程

- 适用于机构联赛、邀请赛、杯赛和多组别综合赛事。
- 使用中性、完整的十六章结构。
- 自动读取当前赛事日期、地点、组别、报名、赛制、名单和纪律参数。

### 中国小篮球赛事规程

- 重点细化低年龄组的上场人数、场地尺寸、比赛用球、篮圈高度、比赛时长、防守方式和分组轮换要求。
- 保留安全、公平参赛和友爱竞赛原则。
- 不生成等级评定、星级评定、技能测试或达标评级相关内容。

### 青少年篮球公开组竞赛规程

- 重点细化实名证件核验、出生日期资格、最低开赛人数、低年龄组特殊规则、友爱规则和家长观赛秩序。
- 积分与奖项参数仍以当前赛事设置为准，不沿用参考赛事的专属积分或晋级资格。

### 青少年篮球精英组竞赛规程

- 重点细化标准场地、完整篮球规则、技术统计、单项奖、申诉程序和赛风赛纪处罚。
- 不沿用参考赛事的品牌、全国赛资格、赞助商或专属处罚期限。

## 生成边界

- 所有模板生成后均为草稿，必须由主办方核对后发布。
- 赛事名称、发布单位、日期、地点、年龄线、名单人数、比赛形式、赛制、费用、奖项和申诉参数来自当前赛事数据。
- 模板文字不能替代当地体育主管部门、场馆、保险和未成年人保护方面的合规审核。
- PDF 与 Word 导出只包含当前赛事已经生成并保存的规程正文。
