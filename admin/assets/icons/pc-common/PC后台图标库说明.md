# 赛小蜂篮球 PC 后台图标库

本目录是机构经营后台、赛事中心和后续教务中心共用的正式图标源，不是页面临时素材目录。

## 当前来源

- 已有项目通用库仍作为第一复用来源。
- PC 后台缺失语义统一采用 [Lucide 官方图标库](https://lucide.dev/icons/)。
- Lucide 采用 ISC 许可；其中部分源自 Feather 的图标采用 MIT 许可，完整文本见 `LICENSE-LUCIDE.txt`。

## 使用约束

1. 页面通过 `manifest.json` 中的语义键选图，不使用字符、Emoji 或 CSS 路径模拟图标。
2. 图标统一保存在 `svg/`，页面不得再复制一份。
3. SVG 通过 CSS mask 继承文字颜色，因此选中、默认、警告状态共用同一源文件。
4. 机构 Logo、赛事 Logo、队徽、球员头像不属于图标，使用用户上传的独立图片资源。
5. 新增图标必须同步登记来源、许可、语义与使用范围。

## 赛事中心首批语义

侧边栏固定使用：工作台、赛事管理、报名资格、抽签分组、球队球员、赛程场次、现场执行、赛果数据。

业务操作已覆盖：搜索、新增、编辑、保存、上传、邀请、绑定、审核、二维码、场地、日历、设备、数据、支付和分账。
