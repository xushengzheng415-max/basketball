# 赛小蜂篮球特色插画图标（推荐版）

## 使用定位

本套为赛小蜂篮球 PC 后台与小程序的**大尺寸功能入口 / 空状态 / 模块引导**图标，作为第一版蓝色方案的品牌色修订版。

- 不替代 16–24px 的按钮、表格、导航等功能图标；此类图标继续复用 `admin/assets/icons/pc-common/svg/` 中的共享 SVG。
- 不直接替换赛小蜂品牌 Logo、球队队徽、用户头像、赛事海报素材或底部 TabBar 图标。
- 当前仅保存为本地设计资产，尚未上传云存储，也未接入页面代码。

## 源文件与质量校验

- 原始 4×4 图标板：`raw/saixiaofeng-basketball-dark-feature-icons-sheet.png`
- 切片数量：16 个透明 PNG。
- 透明背景检查：已在洋红色底图 `qa-magenta-contact-sheet.png` 上检查，无灰底残留或相邻图标串边。
- 重复检查：16 个输出文件的 SHA-256 均不重复。
- 外部授权：本套为本地生成的原创设计资产，不含第三方下载素材。
