# 赛小蜂篮球功能图标包

## 使用范围

本包用于 PC 后台模块入口、小程序功能卡、空状态和运营视觉；不用于 16–24px 的表格操作、导航或表单图标。此类高频功能图标继续复用 `admin/assets/icons/pc-common/svg` 的线框 SVG。

## 固定视觉规范

- 风格：扁平化色块插画，正视角、圆角、无阴影。
- 主色：赛小蜂橙 `#FF7900`。
- 辅色：深海蓝 `#0B2234`、亮青 `#24C6FF`、暖白 `#F7FAFC`。
- 共同元素：每枚图标以篮球与篮球弧线为识别特征。
- 导出：透明 PNG，适合 64px 及以上展示；原始 4×4 图标板保存在 `raw/`。
