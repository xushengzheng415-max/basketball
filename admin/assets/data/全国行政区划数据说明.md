# 全国行政区划数据说明

- 生产文件：`china-regions.js`
- 数据包：`chinese_regions`
- 数据包版本：`0.5.5`
- 数据更新时间：`2026-02-20`
- 覆盖范围：34 个省级行政区、363 个城市层级、3245 个区县层级，包含香港、澳门和台湾地区。
- 上游来源：<https://github.com/kamaslau/chinese_regions>
- 许可证：MIT

页面通过 `window.SXF_CHINA_REGIONS` 读取三级联动数据，兼容直接以 `file://` 打开原型的场景。需要更新数据时，取得新版 `all.min.json` 后执行：

```powershell
node tools/构建全国行政区划数据.js <all.min.json路径>
```

行政区划存在调整可能，正式上线后应建立定期更新机制，并在保存赛事地址时同时保留行政区划编码和当时的中文名称快照。
